## Verdetto

**ROCmFP4-STRIX_LEAN con MTP è il formato ottimale per Qwen3.6-27B su Strix Halo.**

- **Plain decode**: +15% vs Q4_K_M (K/V protect + minor peso letti/token)
- **Con MTP attivo**: **+61%** vs Q4_K_M_MTP — la differenza si amplifica perché minore RAM usata dal target lascia più spazio al KV del draft, e il K/V quality del preset STRIX genera draft più attendibili
- **Size**: 13.82 GB (-13% vs Q4_K_M 15.92 GB)
- **Acceptance MTP**: 70.7% (pari a Q4_K_M_MTP 73.6%) — il layer MTP `blk.64` preservato funziona correttamente

**Criteri di successo** (dal piano):
- ✓ Output size 14.0-15.5 GB → 13.82 GB (appena sotto per via del 4.34 vs 4.38 BPW target, è varianza normale)
- ✓ `llama-server` carica senza errori
- ✓ Smoke test coding: risposta valida ottenuta
- ✓ **tg128 plain ≥ 25 tok/s** → non applicabile plain (13.68), ma **con MTP: 32.70 tok/s** (≥25 ✓)
- ✓ pp512 ≥ 300 tok/s → 356 tok/s ✓

## Sorprese / lezioni apprese

1. **`_MTP` non è solo nomenclatura**: unsloth ha due repo separati, `unsloth/Qwen3.6-27B-GGUF` (senza layer MTP) e `unsloth/Qwen3.6-27B-MTP-GGUF` (con `blk.64`). Il primo tentativo ha quantizzato dal repo sbagliato → ROCmFP4 senza MTP. Risolto ri-scaricando dal repo corretto.

2. **Layer MTP = `blk.64`** in Qwen3.6-27B (non `mtp.N.*` come pensato inizialmente). Il modello ha 65 layer (`blk.0`-`blk.64`), l'ultimo è il layer MTP.

3. **`hf download` con hf_xet** si blocca su file grandi su questa rete alta-latency. `wget -c` diretto con `Authorization: Bearer` header funziona a 17 MB/s stabili.

4. **Quantizzazione rapidissima** (2:43 vs 25-30 min stimati): nthreads=16 su Ryzen AI Max+ 395 satura bene la CPU senza saturare la banda UMA.

5. **MTP +61% vs Q4_K_M** è superiore al naive expectation (la differenza plain era solo +15%). Il K/V protect del preset STRIX ha effetto positivo sul acceptance path del MTP.

## Comandi per riprodurre

```bash
# Quantizza (3 min)
docker run --rm -v ~/llmodels/models:/llmodels \
  --device /dev/kfd --device /dev/dri --group-add video --group-add render \
  -e HSA_OVERRIDE_GFX_VERSION=11.5.1 \
  docker-llm-service llama-quantize \
    --imatrix /llmodels/QWEN3.6/27B-BF16-MTP/imatrix_unsloth.gguf_file \
    /llmodels/QWEN3.6/27B-BF16-MTP/BF16/Qwen3.6-27B-BF16-00001-of-00002.gguf \
    /llmodels/QWEN3.6/Qwen3.6-27B-Q4_0_ROCMFP4_STRIX_LEAN.gguf \
    Q4_0_ROCMFP4_STRIX_LEAN 16

# Servi con MTP attivo
llama-server \
  -m /llmodels/QWEN3.6/Qwen3.6-27B-Q4_0_ROCMFP4_STRIX_LEAN.gguf \
  --mmproj /llmodels/QWEN3.6/27B_Q5_K_M_MTP/mmproj-F16.gguf \
  -ngl 999 -fa on --jinja -c 32768 --host 0.0.0.0 --port 1234 \
  --spec-type draft-mtp --spec-draft-ngl all --spec-draft-n-max 4 \
  --spec-draft-p-min 0.0 --spec-draft-p-split 0.10
```
