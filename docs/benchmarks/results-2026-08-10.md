## Verdict

**ROCmFP4-STRIX_LEAN with MTP is the optimal format for Qwen3.6-27B on Strix Halo.**

- **Plain decode**: +15% vs Q4_K_M (K/V protect + less weight read per token)
- **With MTP active**: **+61%** vs Q4_K_M_MTP — the difference is amplified because less RAM used by the target leaves more room for the draft's KV, and the K/V quality of the STRIX preset produces more reliable drafts
- **Size**: 13.82 GB (-13% vs Q4_K_M 15.92 GB)
- **MTP acceptance**: 70.7% (on par with Q4_K_M_MTP 73.6%) — the preserved MTP layer `blk.64` works correctly

**Success criteria** (from the plan):
- ✓ Output size 14.0-15.5 GB → 13.82 GB (just below, due to 4.34 vs the 4.38 BPW target — this is normal variance)
- ✓ `llama-server` loads without errors
- ✓ Coding smoke test: valid response obtained
- ✓ **tg128 plain ≥ 25 tok/s** → not applicable plain (13.68), but **with MTP: 32.70 tok/s** (≥25 ✓)
- ✓ pp512 ≥ 300 tok/s → 356 tok/s ✓

## Surprises / lessons learned

1. **`_MTP` is not just nomenclature**: unsloth has two separate repos, `unsloth/Qwen3.6-27B-GGUF` (without MTP layer) and `unsloth/Qwen3.6-27B-MTP-GGUF` (with `blk.64`). The first attempt quantized from the wrong repo → ROCmFP4 without MTP. Fixed by re-downloading from the correct repo.

2. **MTP layer = `blk.64`** in Qwen3.6-27B (not `mtp.N.*` as initially thought). The model has 65 layers (`blk.0`-`blk.64`), the last one is the MTP layer.

3. **`hf download` with hf_xet** hangs on large files on this high-latency network. Direct `wget -c` with an `Authorization: Bearer` header works at a stable 17 MB/s.

4. **Extremely fast quantization** (2:43 vs the estimated 25-30 min): nthreads=16 on the Ryzen AI Max+ 395 saturates the CPU well without saturating UMA bandwidth.

5. **MTP +61% vs Q4_K_M** is above the naive expectation (the plain difference was only +15%). The K/V protect of the STRIX preset has a positive effect on the MTP acceptance path.

## Commands to reproduce

```bash
# Quantize (3 min)
docker run --rm -v ~/llmodels/models:/llmodels \
  --device /dev/kfd --device /dev/dri --group-add video --group-add render \
  -e HSA_OVERRIDE_GFX_VERSION=11.5.1 \
  docker-llm-service llama-quantize \
    --imatrix /llmodels/QWEN3.6/27B-BF16-MTP/imatrix_unsloth.gguf_file \
    /llmodels/QWEN3.6/27B-BF16-MTP/BF16/Qwen3.6-27B-BF16-00001-of-00002.gguf \
    /llmodels/QWEN3.6/Qwen3.6-27B-Q4_0_ROCMFP4_STRIX_LEAN.gguf \
    Q4_0_ROCMFP4_STRIX_LEAN 16

# Serve with MTP active
llama-server \
  -m /llmodels/QWEN3.6/Qwen3.6-27B-Q4_0_ROCMFP4_STRIX_LEAN.gguf \
  --mmproj /llmodels/QWEN3.6/27B_Q5_K_M_MTP/mmproj-F16.gguf \
  -ngl 999 -fa on --jinja -c 32768 --host 0.0.0.0 --port 1234 \
  --spec-type draft-mtp --spec-draft-ngl all --spec-draft-n-max 4 \
  --spec-draft-p-min 0.0 --spec-draft-p-split 0.10
```
